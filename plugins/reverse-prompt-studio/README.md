# Reverse Prompt Studio Plugin

这是插件的自包含运行目录，包含本地网页、Node.js 服务、启动 Skill 和图片反推 Skill。工作台支持参考图 + 产品图双图分析，也支持在已有配方中一键匹配新的产品图。

正常用户请通过仓库根目录的 Marketplace 安装，然后在新的 Codex 任务中说“启动图片提示词工作台”。开发时可在本目录运行：

```bash
npm start
npm test
npm run check
```

工作台会缓存 GitHub Release 检查结果 24 小时。发现更高版本时，页面顶部显示一个可关闭的轻量提醒，并提供版本说明和可复制的升级命令；离线或检查失败不影响本地编辑与 Codex 分析。

产品图拥有独立的 `product_truth` 角色：它只控制可见产品特征，不接管参考图的构图、场景或风格。匹配会复用当前 run 的 Codex thread，并遵守板块锁定与真值缺口规则。

## 品牌级精修（0.4）

“品牌级精修”按四个顺序质量门槛检查成图：真实性与物理、艺术指导、品牌与活动、生产完成度。工具只会把最早失败层作为当前修复目标，并把未修改字段全部锁定。

使用流程：

1. 上传待精修成图。
2. 可选上传产品真值、人物、材质、构图或硬结构参考，并为每张图指定一个角色。
3. 填写渠道、受众、第一眼、品牌气质和文案安全区。
4. 选择当前最早失败层中的一个问题，复制 Flow 修复指令。
5. 在外部编辑器执行修复并将结果导回本工具。
6. 只有四层全部 PASS 且没有锁定漂移，才能批准为交付源图。

0.4 不包含工具内直接出修复图，也不自动执行高清放大。直接出图将在 Codex App Server 的图像输出能力和本地文件持久化经过独立验证后接入。

可选环境变量：

- `RPS_PORT`：首选本地端口，冲突时仍会自动回退。
- `RPS_DATA_ROOT`：图片、配方和修订记录目录。
- `RPS_WORKSPACE_ROOT`：Codex thread 的本地工作目录。
- `RPS_SKILL_PATH`：覆盖内置图片反推 Skill。
- `RPS_OPEN_BROWSER=0`：启动后不自动打开浏览器。
- `RPS_DEBUG=1`：输出 Codex App Server stderr。
