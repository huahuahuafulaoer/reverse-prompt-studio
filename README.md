# Reverse Prompt Studio

一个连接用户自己 Codex 的本地图片提示词工作台：放入参考图、生成结构化视觉配方、逐板块编辑和锁定，也可以加入自己的产品图，让 Codex 自动匹配产品特征并整理成新的可复制提示词。

![Node.js](https://img.shields.io/badge/Node.js-%3E%3D18-3C873A)

## 安装到 Codex

准备条件：

- 已安装并登录 Codex CLI。
- 已安装 Node.js 18 或更高版本。

添加插件市场并安装：

```bash
codex plugin marketplace add huahuahuafulaoer/reverse-prompt-studio
codex plugin add reverse-prompt-studio@reverse-prompt-studio-marketplace
```

安装后新建一个 Codex 任务，然后说：

```text
启动图片提示词工作台
```

Codex 会在本机启动服务并打开浏览器。默认地址为 `http://127.0.0.1:4173`；端口被占用时会自动选择其他本地端口。

## 产品图匹配

- 先放参考图，再在下方添加产品图；点击“开始分析”，Codex 会把参考图当作构图、光影和风格来源，把产品图当作产品真值。
- 如果已经得到视觉配方，可以随时更换产品图，再点击“匹配产品”。工具会优先替换产品板块，只在比例、接触、遮挡、阴影或材质受光确有必要时联动相关字段。
- 已锁定的其他板块会继续保留；点击“匹配产品”本身就是对产品板块的明确替换授权。
- 图片无法证明的品牌、工程功能、性能和精确材质规格不会被猜测，而会保留为待确认真值。

## 0.5 更新

- 每个视觉板块都可以直接填写自然语言修改要求。修改动作、主体、构图等关键内容时，工具会同步必要的关联板块、内容锚点、保留项和排除项，避免新要求被旧提示词抵消。
- 每次 Codex 分析或修订完成后，对应任务会自动归档；继续修改同一张图时会恢复原任务并再次归档，减少任务列表堆积，也避免不同图片共用上下文。
- “品牌级精修”调整为完整成稿的摄影真实感与品牌调性优化提示词流程，不再要求用户逐个处理诊断问题。

## 品牌级精修

0.5 中的第二个顶层工作模式“品牌级精修”，把上传图片视为已经完成主体、产品、构图和场景设计的成稿，把精修明确拆成“摄影真实感”和“品牌调性”两条线。

系统会自动从光影一致、材质响应、皮肤真实、景深与锐度、成片收口中选择 1–4 个有可见依据的真实感处理项。用户只需按需补充一句品牌调性；系统会把它转译为色调曲线、色彩平衡、光质、对比、饱和度与表面完成度。不填写时只提升真实感并延续原图，不擅自增加“电影感”或“高级感”。

生成的整图精修提示词由服务端固定加入人物、产品、装备、文字、构图、裁切和场景结构的不可变边界，再复制到固定的图片编辑或生图工具执行。它会主动限制全局磨皮、全局锐化、HDR、假毛孔、重复纹理和套滤镜式品牌化。

0.5 不包含工具内直接出修复图，也不自动执行 Real-ESRGAN 或其他高清放大。纯高清放大仍属于独立后处理步骤。

## 更新

当仓库发布新版本后，刷新插件市场并重新安装：

```bash
codex plugin marketplace upgrade reverse-prompt-studio-marketplace
codex plugin add reverse-prompt-studio@reverse-prompt-studio-marketplace
```

更新后请新建一个 Codex 任务，让新技能和代码生效。

从 `v0.2.0` 开始，工作台启动时会低频检查最新 GitHub Release。只有发现更高版本时，页面顶部才会出现更新提醒，可查看版本说明、复制升级命令或暂时忽略该版本。提醒不会自动升级插件，也不会中断正在进行的分析。

> 已安装 `v0.1.0` 的用户需要手动完成一次上述升级；从 `v0.2.0` 起，后续版本才会在工具内主动提示。

## 隐私与运行方式

- 浏览器只连接 `127.0.0.1` 上的本地服务。
- 服务调用用户本机的 `codex app-server`，使用用户自己的 Codex 登录、权限与用量。
- 参考图、产品图、配方和修订记录默认保存在用户自己的应用数据目录，不会写入插件安装目录。
- 图片分析仍会按照用户自己的 Codex 配置发送给模型处理；本插件不包含共享 API Key，也没有独立的第三方上传服务器。
- 为显示版本提醒，服务每天最多向 GitHub 公共 Release API 检查一次版本号。这个请求不包含图片、提示词或分析记录；检查失败时静默跳过。

## 本地开发

```bash
npm start
npm test
npm run check
```

应用源码和插件清单位于 [`plugins/reverse-prompt-studio`](plugins/reverse-prompt-studio)。仓库本身同时是一个 Codex Plugin Marketplace。

## 发布迭代

GitHub 不会自动同步尚未提交的本地修改。完成一次迭代后，需要运行测试、提交并推送到这个仓库；用户再执行上面的更新命令即可取得新版。插件版本记录在 `.codex-plugin/plugin.json`。
